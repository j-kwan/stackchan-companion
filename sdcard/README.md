# sdcard/ — template of the SD card contents

Copy the CONTENTS of this directory to the root of the SD card (FAT32).

```
/companion.bin               SD-Updater restore binary — NOT shipped here:
                             produced by the launcher's [SauverFW] (swipe down), or
                             copy .pio/build/companion/firmware.bin renamed.
                             A release's SD zip already includes it, with the
                             guest apps in /bins/ (docs/INSTALL.md)
/bins/*.bin                  launchable binaries (touch launcher + [Bins] API)
/dances/*.csv                custom choreographies (docs/reference/CHOREGRAPHIES.md §6
                             — sample provided; manageable from the console/API)
/sounds/*.wav                optional samples (replace the chirps — future)
/stackchan-companion/config.yaml  configuration (full schema: docs/reference/CONFIG.md)
/stackchan-companion/rules.txt    reactive rules (docs/reference/PLUGINS.md) — NOT
                             shipped here: the firmware writes a commented
                             template itself the first time it finds none
                             (src/app/RuleStore.h). rules.txt.example beside
                             this file is a MIRROR of that template, so it can
                             be read without owning the robot — the two are
                             compared by scripts/gates/check-mirrors.py
/stackchan-companion/ha-remote.yaml    config of the ha-remote guest bin: host, Home
                             Assistant token (docs/guests/HA-REMOTE.md)
/stackchan-companion/flightradar.yaml  config of the flight-radar guest bin: lat/lon OR
                             airport (IATA/ICAO), radius_nm 10..500, poll_s,
                             api, tz_offset_h (docs/guests/README.md)
/stackchan-companion/space.yaml        config of the space guest bin: observer lat/lon/
                             alt_m, tracked NORAD id, min_pass_el, theme, auto_bright
                             (docs/guests/SPACE.md)
/stackchan-companion/runways.csv  runway database of the flight-radar METAR rose —
                             OurAirports (PUBLIC DOMAIN), fixed-width records
                             of 17 bytes searched by bisection. Regenerate with
                             python tools/generators/make-runways.py (~236 KiB;
                             docs/guests/FLIGHT-RADAR.md)
```

Notes:
- Everything is optional — with no SD card or no key, the compiled defaults apply.
- ⚠ `config.yaml` holds the WiFi and API passwords **in clear text**, and the
  card is not encrypted. What that means for the robot on your network:
  [`docs/reference/SECURITY.md`](../docs/reference/SECURITY.md).
- `config.yaml` is fully REGENERATED by the firmware on every POST
  /api/tuning or /api/wifi: only the `wifi:` and `tuning:` sections are
  read back at boot, hand-written comments are lost on the 1st save.
- Uploading a .bin without pulling the SD card out: `POST /api/bins`
  (multipart) then `POST /api/bins/launch?name=xxx.bin`.
